# Seven-day first-release plan

A week can produce a tested beginner release. It cannot honestly produce thousands of expert-reviewed multilingual levels. The current 0.7 app is the usable foundation for that release; the complete curriculum remains the product roadmap.

| Day | Deliverable | Release gate |
| --- | --- | --- |
| 1 | Design system, Mia, responsive learning shell, device-local state, real reference lessons | Small/large screens, reload recovery, no fabricated content counts |
| 2 | Primary-source review of the reference lessons; Hindi/Hinglish editing; prioritise missing everyday-money topics | Reviewer sign-off and recorded source dates |
| 3 | Add focused lessons on banking, inflation, credit, debt repayment, insurance foundations; extend interactions | Each lesson's arithmetic recomputes; no stale rule embedded in text |
| 4 | Finish the beginner release content batch, revision UX, backup, and onboarding/placement scope | A novice can complete the whole shipped path and understand the next step |
| 5 | Physical low-end Android tests, TalkBack, 200% text, offline recovery, screen-reader and keyboard audit | No blocker in a full install → learn → export → restore journey |
| 6 | Review performance, native SQLite/Auto Backup, file sharing, permissions, crash paths, release signing | Measured cold start and scrolling on target hardware; signed release candidate |
| 7 | Final content approval, APK/AAB verification, HTTPS deployment and PWA install test, release notes | Approved artifacts, rollback plan, and clearly bounded content claims |

This is a work plan, not a claim that future steps have been executed or an unattended commitment to deliver later.

## Subsequent content releases

- Expand World 0 to full coverage first. Do not rush advanced markets ahead of fraud safety, debt, and insurance.
- Then economics and investing fundamentals, mutual funds, shares, business analysis, and protection.
- Follow with fixed income, retirement, indexing, gold, and property.
- Publish technical analysis, derivatives, complex alternatives, and integrated capstones only after prerequisites and risk review.
- Use the same reusable lesson schema, progress IDs, notes, and review history. Budget editorial capacity in addition to engineering time.

## Scope still outstanding

The remaining 10 of 16 exercise forms; four-level depth ladders; soft prerequisites; placement and goal tracks; crowns; checkpoints/exams/certificates; structured financial-rule updates; expanded glossary and calculator catalogue; historical paper trading, bond/option/DCF simulators; richer notes/highlights; optional notifications; short progress codes/QR transfer; complete interface localisation; Android native read-aloud; human financial and language review; physical-device performance and native restoration tests.

Google sign-in and cloud sync remain intentionally outside the first release. Do not add accounts or trackers to compensate for missing local reliability.
