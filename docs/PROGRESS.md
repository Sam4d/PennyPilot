# Overall project completion estimate

Current estimate: **about 10% of the full agreed project**. This is a coarse planning estimate, not measured hours, a release certification or a claim that 10% of the curriculum is ready. Report an updated overall estimate at the end of each task response. Keep the denominator consistent; do not substitute completion of the latest patch or the beginner preview.

The weighted estimate rounds to about 10%. These weights are explicit planning judgements and can be revised if the user changes scope. Source availability and review capacity affect completion; a source link alone does not count as review.
