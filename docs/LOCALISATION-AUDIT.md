# Hindi interface audit

18 October 2026 (India). This is the review list **before shipping** the 0.8 interface changes. English remains simple standard English. Hindi uses Devanagari with familiar finance abbreviations. Language-option names, Penny Pilot, source domains, ₹, XP, EMI, SIP, PDF and recognisable glossary headwords are intentional exceptions. Personal notes/names/reports are not translated or overwritten. Supplied long-term catalogue outlines remain English planning content; their full Hindi authoring is not claimed.

The list below covers static interface copy and dynamic-label fragments. Existing lesson/guide translations remain in their authored content files. No translation is claimed to have independent native-editor approval.
