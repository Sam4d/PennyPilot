# Identity-safety visual review — 23 October 2026

`before/` captures the existing 0.9 production output before rebuilding: Learn, About and S0.9.2 (an outline at that time). `after/` captures the 0.10 build for the same routes, plus the first teaching card and initially collapsed inspection board. Both cover 360×800 / 1440×900, English/Hindi, light/dark and reduced motion. `board/` captures the third fictional case after all clues and safer-response feedback are opened. Contact sheets help comparison; individual PNGs retain the original viewport dimensions. These are browser screenshots, not physical-device photos or a performance certification.

## Observed and remaining issues

- The catalogue now offers the actual identity-safety draft while preserving direct topic access. The original topic heading remains English in Hindi mode, consistent with the documented catalogue localisation backlog.
- English and Devanagari teaching/board copy are legible in both themes. Cases wrap into full-width phone buttons and three desktop choices. Selection has text/pressed state and a border as well as colour. No board field requests a real code or opens the fictional address.
- The original upper lesson layout and concept controls remain. Longer prose and nine optional clues require vertical reading on a phone; the fully expanded board does not fit in one viewport. Clues start collapsed, and scenario changes reset the displayed clue count and feedback. This is a deliberate reading interaction, not a claim that every control is simultaneously visible.
- Existing nested card borders are visually dense when several clues are expanded. The board is usable and spacious, but a future editorial/design pass should assess passage length and screen-reader announcements with learners rather than declaring the layout final.
- Automated checks cover 44px button heights, accessible names/expanded state, whole-page axe scans and 200% text without document/dialog horizontal overflow. Real-device touch, TalkBack, low-end performance and native-language editorial quality remain unverified.
