## Honest critique

The existing white/charcoal/green hierarchy and Mia remain intact. Inventory counters, draft wording and app version now reflect 20 lessons / 160 exercises / 50 glossary entries / 0.9.0. The payslip topic changes from an outline to an authored lesson launch; the original outline remains explicitly unverified planning content. The catalogue's original English titles/outlines remain a Hindi-localisation backlog, distinct from the new fully translated lesson material.

The phone reading cards and boards are deliberately longer. They require vertical reading; not every control fits the first viewport. The first payslip prototype put changed totals above the viewport when a row was open, so each active slider now repeats annual cost and monthly cash beside it. A browser assertion checks that its changed bank amount is in view after focusing the control. This makes the consequence visible rather than asking learners to remember a number above the fold.

Seven concept controls keep 44px targets inside their own horizontal strip. The selected final control remains visible when moving with Next; other four-card lessons retain their existing layout. Cash-flow months use a separate horizontal strip; partial neighbouring buttons indicate more months and can be reached by tapping, keyboard focus or scrolling. Only the selected month is detailed, avoiding a tiny six-column table on phones.

Hindi labels and explanations wrap without the inspected clipping or document overflow. The figures stay readable in both themes. Automated axe checks caught an invalid definition-list note in the first prototype; moving the note into a valid description fixed it. The multi-lesson cash-flow topic uses distinct accessible launch names and retains the original lesson. Long path groups split at six nodes rather than overfilling a card.

Not verified: novice comprehension, human native-language/financial review, physical touch-frame performance, TalkBack pronunciation and real-device WebView rendering. Screenshots and axe are evidence for the tested states, not a universal usability or performance certification.
